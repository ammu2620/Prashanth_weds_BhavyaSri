EASY EDITING
Use config.js for the main editable details:

- Wedding date/time
- Church/address
- Google Maps link
- Lunch wording
- Bible verse
- RSVP email

RSVP EMAIL
Replace:
rsvpEmail: "YOUR_EMAIL@example.com"
with your real email address if you want RSVP responses delivered by email.
The first FormSubmit test may ask you to confirm the email address.

GITHUB PAGES
1. Delete the OLD invitation files from your GitHub repository.
2. Extract this ZIP.
3. Upload index.html, style.css, script.js, config.js and the assets folder.
4. Keep index.html/style.css/script.js/config.js in the repository root.
5. GitHub > Settings > Pages.
6. Deploy from a branch > main > /(root).
7. Save.
8. Wait about 1–2 minutes.
9. Open your website with ?v=ultimate-final at the end of the URL.
